RoxStar is a **fan-made** server (and client) implementation of the Moshi Monsters flash game API in NodeJS. **By using, copying, or modifying this software you are agreeing to the terms laid out in the [License, EULA, and ToS](https://github.com/kleineluka/roxstar/blob/main/LICENSE).** While the server is mostly complete, this project is still in early development and not ready for general use. The **current version** of this software is `0.0.1` - you can also see a [Changelog](https://github.com/kleineluka/roxstar/blob/main/CHANGELOG.md) of notable updates and changes.

## Features 🦋
- Client
    - Flash Support on Chromium
    - Server Browser and Management
    - Local Resource Loading
    - Settings, QoL and Themes
    - Developer Tools
- Server
    - Parity with original API
    - Fast, Lightweight, and Secure
    - Staff Panel and Moderation Tools
    - Developer Tools and Debugging
    - Extensive Configuration
    - Resource Manifest Offloading
- Open Source with RoxStar License (see below)
- Clean-Room Implementation
- Testing Scripts
- Readable Codebase (😅 mostly!)

When development is near completion, more in-depth documentation will be provided.
